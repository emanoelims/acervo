Enum behaviour

Functions for working with collections, known as enumerables. In Elixir, an enumerable is any data type that implements the Enumerable protocol.

iex> Enum.map([1, 2, 3], fn x -> x * 2 end)
[2, 4, 6]

Some functions, like reduce/3, are the building blocks of the others.

mix test --only enum

map(enumerable, fun)

Returns a list where each element is the result of invoking fun on each corresponding element of enumerable.
